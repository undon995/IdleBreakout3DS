# Contributing

Contributions are welcome after the maintainer confirms distribution permissions.

- Keep changes focused and describe what changed and why.
- Build the 3DSX version with `BUILD_MSYS2.sh` before submitting changes.
- For changes affecting CIA metadata, test `BUILD_CIA_MSYS2.sh` as well.
- Include the 3DS model and reproduction steps with bug reports.
- Avoid unrelated website files, generated temporary build output, and platform-specific executable tools in commits.
- Keep original game attribution and document approximated or incomplete mechanics accurately.
